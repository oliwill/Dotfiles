# 实体页面模板

播客 wiki 中的"实体"包括人物、话题、机构/作品。每种类型有标准化模板。

## 三种实体类型

| 类型 | 命名 | 示例 |
|------|------|------|
| **人物** | 中文姓名 / 英文名 | `梵一如.md`、`Phil张哲.md` |
| **话题** | 概念名 | `中日关系.md`、`身份认同.md` |
| **机构/作品** | 全称 | `番薯剥壳工作室.md`、`东亚观察局.md` |

## 模板 1: 人物页面

```markdown
---
title: "{姓名}"
description: "{身份/角色描述}"
tags: ["主播|嘉宾|学者|政治家", "...", "...", "...]
role: "{主要角色}"
created: {YYYY-MM-DD}
updated: {YYYY-MM-DD}
---

# {姓名}

## 身份

- **{主要身份}**
- **{次要身份}**
- {其他相关信息：组织、母校等}

## 出场节目

- [[EP{N}-...]] — {一句话说明本期角色}
- ...

## 关注领域 / 研究方向

- {领域1}
- {领域2}

## Related

- [[相关人物1]] — {关系说明}
- [[相关话题1]] — {为什么相关}
- [[相关机构]] — {归属或合作关系}
```

### 人物页面要点

- **不要**写百科式简介（避免 AI 编造）
- **要**写在节目中的角色和讨论范围
- **必须**至少 3 个 wikilink 反向引用

## 模板 2: 话题页面

```markdown
---
title: "{话题名}"
description: "{一句话定义}"
tags: ["地区|领域", "类型", "..."]
created: {YYYY-MM-DD}
updated: {YYYY-MM-DD}
---

# {话题名}

## 定义 / 简介

{1-2 段话定义这个话题，建立基本理解}

## 当前状况 / 关键论点

### {子话题 1}

- {要点1}
- {要点2}

### {子话题 2}

- {要点1}

## 关键人物

- [[人物1]] — {在该话题中的角色}
- [[人物2]] — {...}

## 相关讨论节目

- [[EP{N}-...]] — {本期如何涉及这个话题}
- ...

## Related

- [[相关话题1]] — {关系类型：因果/对比/包含等}
- [[相关话题2]] — ...
```

### 话题页面要点

- **不要**做无中生有的扩展（只写节目里讨论过的）
- **要**保留观点的多元性，不要做单一叙事
- **必须**有"相关讨论节目"章节，明确引用来源

## 模板 3: 机构/作品页面

```markdown
---
title: "{名称}"
description: "{一句话简介}"
tags: ["播客|工作室|书店|...", "..."]
created: {YYYY-MM-DD}
updated: {YYYY-MM-DD}
---

# {名称}

## 简介

{1 段话介绍这个机构/作品}

## 关键信息（如适用）

- **类型**: {播客/工作室/出版社/书店}
- **创立时间**: {年份}
- **创始人**: [[人物名]]
- **作品/产品**:

## 关联人物

- [[人物1]] — {角色}
- [[人物2]] — ...

## 关联讨论

- [[EP{N}-...]] — {如何被提及}

## Related

- [[父机构]]
- [[子作品]]
- [[竞争/合作机构]]
```

## 通用约束

### Frontmatter 必备字段

每个实体页面都必须有：
- `title` - 与文件名一致
- `description` - 一句话简介（用于搜索）
- `tags` - 至少 2 个标签
- `created`、`updated` - 创建和更新日期

### 内容规范

- **不写百科式开头**："X是一个..."（容易让 AI 编造细节）
- **写来自节目的事实**："X在 EP279 中被讨论..."
- **保持观点的可追溯性**，每个论点都有 source

### Wikilink 互链

- 每个实体页面至少链接 3 个其他实体
- 避免单向链接：A 链 B，B 也应该链 A
- 用 `## Related` 章节统一收尾

## 反模式

❌ **过度详细的人物简介**
```markdown
高市早苗，1961年生于奈良县，毕业于神户大学经营学部，
从政前曾在松下电器工作...
```
（这些信息不是从节目里来的，可能不准确）

✅ **来自节目的事实**
```markdown
## 政治特点

### 决策风格（来自 EP279）

- "乾纲独断"倾向明显
- 与自民党高层、精英官僚有嫌隙
```

## 常见错误

1. **复制百科**：实体页面不是百科，是节目讨论的索引
2. **没有反向链接**：忘记加 `## Related`
3. **Wikilink 自指**：A 页面里链 `[[A]]` 是错的
4. **过度细分**：把"日本右翼"和"日本极右化"做成两个页面（应合并）
