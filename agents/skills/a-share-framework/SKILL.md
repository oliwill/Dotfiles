# A股七层决策链分析框架

**一句话原则**：财报决定**买什么**（质），技术决定**何时买卖**（时），资金结构决定**信不信**（印证），计划决定**亏得起多少**（命），情绪管理决定**能不能活到下一轮**（寿）。

**七层链条，顺序不可乱**：世界观 → 选股 → 择时 → 操作 → 组合 → 心智 → 复盘。任何一层 gate 不过，链条终止，输出对应处置（观望/删除自选/入观察池），绝不硬推结论。

> 免责声明：本框架输出为研究分析，不构成投资建议。所有买卖决策与后果由用户自负。

按优先级检测可用数据源，构建决策树，**绝不假设**：

```bash

!`test -f run_analysis.py && echo "REPO_PIPELINE_OK" || echo "NO_REPO"`
# 1b. 检测 longbridge CLI
!`longbridge --version 2>/dev/null || echo "NO_LONGBRIDGE"`
# 1c. 检测 python 数据库
!`python -c "import yfinance" 2>/dev/null && echo "YF_OK" || echo "NO_YF"`
!`python -c "import akshare" 2>/dev/null && echo "AKS_OK" || echo "NO_AKS"`
```

决策树：

| 检测结果 | 数据路径 |
|---|---|
| REPO_PIPELINE_OK | **首选**：`python run_analysis.py <CODE>` 取全量 JSON；HK/A股用 `python one_shot_analysis.py <CODE>`（超时隔离） |

数据源细节与字段映射见 `references/data-sources.md`。

## Step 2: 世界观层 Gate（大环境允许出手吗？）

拉取并判断四项，输出三档结论：**SAFE / CAUTION / UNSAFE**。

1. **流动性与利率方向**：CPI（容忍线 3%、宽松线 2%）+ 基准利率动向 + 无风险利率 i 的方向（低 i 利好成长，高 i 利好成熟现金流）。
2. **政策友好度**：媒体热度反身性（"订单多业绩好股价不涨"=转折预热；国资违法集中曝光=政策不友好开始）。
3. **市场叙事位置**：当前牛市/熊市所处阶段（政策驱动→戴维斯双击→鸡犬升天）；化债叙事完成度。
4. **先行指标**：利率债走势（领先股市约 2 周）、指数与 850 日均线（基钦周期）关系。

**Gate**：UNSAFE → 终止链条，输出「观望计划」（空仓也是计划）；CAUTION → 后续所有仓位建议减半并注明。细则见 `references/macro-regime.md`。

## Step 3: 选股层 Gate（这家公司干净吗？）

对利润表带怀疑态度、资产负债表带研究态度、现金流量表带辩证态度。**疑心即弃：解释不清楚≈有问题，不需要证据确凿**。

执行红线清单（逐项给证据或标注"数据缺失"）：

| # | 检查项 | 红线 | 数据源 |
|---|---|---|---|
| 1 | 审计意见 | 保留/无法出具/否定 → **VETO** | 年报首页 |
| 2 | 存贷双高 | 存款高+贷款高并存 → **VETO** | 资产负债表 |
| 3 | 双高 | 高库存+高毛利+周转连降 → **VETO** | 年报+同行对比 |
| 4 | 应收恶化 | 应收增速持续>收入增速+回款低于行业且逐年降 → VETO | 三表 |
| 5 | 净利润现金含量 | 长期显著<1 → 降档观察 | 现金流量表 |
| 6 | 对敲嫌疑 | 分时多毛刺+爆量缩量急+低市值 → **VETO** | 分时图 |
| 7 | 解禁临近 | 产业基金/大股东解禁期近 → 禁重仓，已有仓位止盈 | 公告 |
| 8 | 疑似逃废债 | 突击计提/存货骤降非因销售 → **VETO** | 公告+三表 |

任一 VETO → 终止链条，输出「删除自选」及证据链。公式、例外辨析（茅台型稀缺品、地产水电预收款）、产业链定位（卖水人/产业基金影子股东/横向补涨）见 `references/red-lines.md`。

## Step 4: 择时层（现在能买吗？）

按固定顺序综合三大支柱，**判趋势→量位置→定时间**，不许只用单一工具下结论：

1. **道氏判势**：主趋势方向（周/月线）、所处阶段、资金五分类谁在场、颈线（交地/衢地）得失、九地结构（散地=板块各自为战时个股独涨不作板块信号）。
2. **波浪量位**：推理"现在站在哪"而非预测"涨到哪"；A 股扁浪特征（别拿美股标准浪硬套）；警惕 B 浪反弹（不创新高是正常 B 浪，新高后 C 浪必杀）。
3. **江恩定时**：24 节气时间窗（四正>四立）+ 重要成交量 + 龙头转向=转折三因素；执行「预设—求证—操作」：左侧预设、右侧求证、分批动手。
4. **K线量能求证**：灵敏度 K线>量>均线>MACD；均线/MACD 是二级信号只做风控不做预测（金叉死叉基本不准）；大周期对小周期降维打击，大小周期必须相互印证；量能四态（温和/暴力/地量/恐慌盘）定性当前位置。

输出：当前位置判定（趋势/浪位/时间窗距离）+ 买卖信号证据链（每条注明时间级别）。形态操作链（W底/M顶/多方炮/螺旋桨/抄底三条件）、指标骗术识别、盘口信号见 `references/timing-playbook.md`。

## Step 5: 操作计划（Gate：建仓绝对前提）

**建仓绝对前提，三条同时满足，缺一不可**（要求背下来）：

1. 标的处于明显缓步上涨趋势，或经长时间调整盘出下降通道且成交量衰竭；
2. 基本面过硬、企业存续无忧（已过 Step 3）；
3. 大盘环境安全（已过 Step 2）。

不满足 → 输出「入观察池」+ 等待条件清单。满足 → 填写 **13 字段操作计划**：

标的/行业/买入理由（基本面+技术面分开写）/大盘环境判断/建仓价位区间/计划仓位/止损位（价格+逻辑）/目标位与盈利预期/加仓条件与阶梯/持有周期/验证时间点（财报窗、时间窗）/退出条件/最坏情况与应对。

默认参数（用户未指定时必须使用）：

| 参数 | 默认值 | 为什么 |
|---|---|---|
| 止损 | 建仓价下 8-12%（默认 10%） | 单次损失可承受；低于 8% 易被震出，高于 12% 伤本金 |
| 首仓 | 总资金 10%（风偏极低 5%） | 反对全仓杀进杀出；循序建仓才能逐步印证买点 |
| 安全垫止盈 | 浮盈 20% 减 1/4；30% 减半仓 | 跌幅须超垫子才侵蚀本金=用利润抗波动 |
| 加仓 | 相对低区技术点 或 绝对低区（沪深300 PE<12/<10，仅熊市左侧） | 加仓≠追涨 |
| 风报比 | 必须≥2:1，写明数字 | 不合理的计划不许执行 |
| 纪律 | 连续错 3 次停下休息 | 情绪变形期的最大保护 |

加仓阶梯（2015 沪深300 模板）、止损后处理、隆基五卖点减仓链、组合结构（6 成固收+4 成风险）见 `references/operation-templates.md`。

## Step 6: 组合定位（这笔头寸的角色）

明确该头寸在组合里的角色再定仓位上限：**固收底仓（6 成，国债ETF/货基）/ ETF Beta（宽基优先）/ 个股 Alpha（≤4 成，分 2-3 组）**。检查与现有持仓的相关性（鸡蛋不放一个篮子的真义=找相关性不显著的标的）；同题材集中度高的要降档。绝不推荐：新发行热门主题基金、解禁期临近重仓、信用债/垃圾债。

## Step 7: 输出分析报告

固定七节，**每节给证据，没证据写"数据缺失"，绝不编造**：

```
# <代码> <名称> 分析（<日期>）
1. 世界观结论：SAFE/CAUTION/UNSAFE + 四条判断要点（各一行）
2. 选股结论：PASS/VETO + 红线清单逐项打勾/打叉（VETO 项给证据）
3. 择时结论：当前位置判定（趋势/浪位/时间窗）+ 信号证据链（注明级别）
4. 综合裁定：【买入计划 / 入观察池 / 回避删除 / 空仓观望】四选一 + 一句话理由
5. 操作计划（仅裁定为买入计划时）：13 字段全填，风报比数字写明
6. 组合建议：角色 + 仓位上限 + 相关性提示
7. 验证与复盘锚点：未来 2-4 个验证时间点（财报窗/节气窗/颈线位）+ 各自的多空判据
```

裁定四档的行为定义：**买入计划**=三前提全过+计划可执行；**入观察池**=质地过但时机未到，给出等待的具体条件（如"缩量回天量一半以下""颈线站稳三天"）；**回避删除**=红线触发，附证据；**空仓观望**=世界观 UNSAFE。
