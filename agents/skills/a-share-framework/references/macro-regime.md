# 世界观层细则（宏观与政策判断）

> 核心信念：**流动性决定市场大方向**。分析顺序固定为 宏观→政策→产业→技术，绝不用一根 K 线反推宏观。

## 1. 简化宏观包（只看三样，别陷入经济学细节）

- **CPI**：容忍线 3%——之下基准利率通常不动；低于 2%=政策偏宽松。通胀顽固→提 i→资金循环减速→资产缓跌。
- **基准利率 / 无风险利率 i**：i 是牵一发动全身的变量。**低 i 刺激新兴产业投资，高 i 刺激成熟 FCF 充裕公司**（热向好 vs 冷避险）。i 全球联动（美=脑、日=心、中=四肢、韩=肺），脑子出问题四肢难独强，但受伤最轻。
- **重要会议公报**：前两季不及预期→**10 月末 11 月初会议出针对性措施=资金做多最关注的方向**。公报措辞克制，一句话背后是整条产业链，需自行推测；抓一两个词炒题材=市梦率，是对公报的不理解。

## 2. 政策友好度（反身性观察）

- 媒体热度=政策友好的镜子：绩优→引流→关注→绩优放大，反身定理无处不在。
- **国资企业违法行为集中曝光=该行业政策不友好阶段的开始**。
- **"订单多、业绩好、就是股价不涨"的密集报道=政策转折的舆论预热**。
- 枪打出头鸟：行业"特别强"就会被审视；资金喜欢四平八稳。
- 以上是经验规律，必须从盘面聚焦反复考证，不单独据此操作。

## 3. 市场叙事位置

- 牛市三阶段（道氏）：政策驱动→戴维斯双击→鸡犬升天。先定位阶段再定预期。
- **本轮牛市=化债逻辑**：地方政府摆脱土地财政、与资本市场直接握手；**化债不完成，牛市不会结束**。化债超 2/3 后进入央企收购不良资产+行政规划改革阶段（地产央企龙头受益）。
- 通缩周期尾声：高科技类大放异彩；但政策收益兑现+产业基金临退出时，不买新发行同类主题基金。

## 4. 先行指标

- **利率债领先股市约 2 周**（通胀升温利率债先跌）。要分得清日常波动与标志性下跌 K 线——分不清时此指标弃用，不硬用。
- **850 日均线=基钦周期（40 个月库存周期）**：指数反复顶碰 850 日线=被忽略的长期积极信号；周期逆转级别很高，更靠近宏观判断而非操作信号。

## 5. 大环境六特征（SAFE/CAUTION/UNSAFE 判定）

逐项判断：①流动性方向 ②政策友好度 ③叙事阶段 ④利率债信号 ⑤指数与 850 日线关系 ⑥国际资本流动（美元指数/汇率/北向）。
- ≥4 项正面 → **SAFE**
- 2-3 项正面 → **CAUTION**（仓位建议减半）
- ≤1 项正面 → **UNSAFE**（输出观望计划，终止链条）

## 6. 金融本质（防骗世界观）

- **镜像原理**：多空一理，不问善恶，观察缝隙与瑕疵。
- **信息半对称**：你知道的主力都知道，主力知道的你不全知道——**"说什么不重要，做什么最重要"**（看资金流、持仓公告、产业基金进出，不听故事）。
- 产业周期联动：地产（土=权威）退→白酒低迷；猪周期=人制造（纵向并购降价→利润上下游摊薄→ROE 走低）；化债周期=本轮牛市燃料。
