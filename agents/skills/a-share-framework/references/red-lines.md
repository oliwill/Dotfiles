# 选股层细则（财报排雷与产业链定位）

> 态度：利润表带**怀疑**态度，资产负债表带**研究**态度，现金流量表带**辩证**态度。
> 总原则：**疑心即弃——解释不清楚≈有问题，不需要证据确凿**（行业毛利 35% 它报 70%、产品市面买不到 → 删）。

## 1. 粗筛（30 秒生死线）

年报第一页审计意见：标准无保留=合格；附说明无保留=有问题但责任清晰可查；**保留意见/无法出具意见=VETO；否定意见=报警级远离**。
披露节奏：年报（4 月底前，必审计）＞半年报＞一季报＞三季报。

## 2. 指标公式组（连续 3 年 + 同行对比）

| 指标 | 公式 | 判据 |
|---|---|---|
| 变现速度 | 货币资金/应收账款 | 宜略大；太小或连年大波动=警惕（赊销放宽或虚构收入） |
| 应收/收入 | 应收增速 vs 收入增速 | **应收明显>收入+回款低于行业且逐年降=VETO**（四川长虹模板） |
| 净利润现金含量 | 经营现金流净额/净利润 | **长期显著<1=利润没变现金**（滞销或赊销） |
| 净现比 | 同上分行业看 | >1 好（**地产/水电不适用，有预收款**） |
| 存贷双高 | 存款高+贷款高并存 | **不合逻辑=VETO**（康美模板：存款系伪造） |
| 双高 | 高库存+高毛利+周转连降 | **不合商业逻辑=VETO 前兆**（恒大模板：库存摊薄毛利率合法，但销售决定生死） |
| 产销比 | 生产量/订单量 | **超 30% 无合理解释=出问题**（车企尤甚） |
| FCF | 经营现金流净额-CapEx | 持续为正=抗风险；**FCF≈股东权益**；不分红+闲钱买理财=没想回报股东 |
| 现金循环周期 | 同行对比 | 显著高于同行=盈利质量差（康得新模板）→ 走，不深究 |
| 对外投资 | 金额大+标的看不懂 | 几年后大额计提（医疗并购对赌失败高发） |

## 3. 例外辨析（别误杀）

- 稀缺性产品（茅台型）：价格弹性好，不受价格粘性束缚（跌则库存出清）；净现比从 1.07→0.75=渠道从持币等货变囤现货，是观察信号不是 VETO。
- 新兴行业研发压低利润：可睁一只眼闭一只眼，**但睁开的那只眼不能见利润就放光**。
- **PE 思辨**：高科技研发压低利润→高 PE 被动合理；充分竞争行业→低 PE 合理。**PE 低≠便宜，高≠贵**。虚增利润的目的=制造戴维斯双击假象。
- 口诀：**家有万贯，带毛的不算**（农林牧渔高毛利不可信，减值吓人）。

## 4. 产业链定位（买"谁"比买"什么"更重要）

- **横向对比找补涨**：板块受资金加持时龙头启动早于板块→①直接买 ETF；②找"排名靠前+业绩稳+涨幅未起"的二线龙头做补涨计划。
- **产业基金影子股东**：业绩与股价的保底标志。未退出前震荡可安心；**解禁期临近常有一波拉升，但公告要退出=止盈信号**；提前推算解禁期，**绝不在解禁前重仓杀入=接盘侠**。
- **卖水人策略**：题材启动时沿供应链找贯穿型设备/服务商（如医药链的制药装备、低温冷链、CRO），不追龙头本身。
- **并购审查**：大而全纵向并购=各环节利润摊薄、ROE 走低（猪周期其实是人制造的）；查并购背后利益输送。
- **田野调查**：产品市面买不买得到、经销商怎么说、股东背景（信用套利）。獐子岛一句话破案："笼子里没苗，有石头。"

## 5. 主力视角反证

- 大资金更了解质地：造假曝光前资金往往已出逃做成顶部形态（上海物贸三重顶）。
- **亏损股大跌主力放量跟进≠活雷锋→去现金流量表找答案**（现金流量表最能反向印证发展质量）。
- **好公司≠好股票≠好买点；好价格≠好买点**。主力懂价值所以不给你买点；能让你轻松挣钱时，准是上涨末端他想走。
- **技术信号未必全对，但用来做风控足以躲避财务大雷**（康得新：见单杀单+颈线墓碑+45°分时下杀，一路都是减仓点）——被堵在雷里多半是装鸵鸟。
